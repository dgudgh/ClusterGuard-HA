ClusterGuard HA 2.2.42 发布说明#

语言： English | 简体中文

发布日期：2026-08-28
版本：2.2-42

版本概述#

v2.2.42 修复图形化升级包上传权限，并完善滚动升级中断后的续跑、回退和状态展示。本版本只更新 ClusterGuard 控制面、Agent 和升级工具，不修改数据库软件、数据目录、复制关系或业务入口。

主要变化#

  • RPM 安装后将签名升级包检查程序限定为 root:clusterguard 0750，控制服务可以验包，普通本机用户仍不能执行。
  • 验包程序无法启动时，控制 API 返回真实系统错误，不再显示缺少原因的空错误。
  • 升级包不再携带构建主机的扩展属性，避免 Linux 解包时出现无关告警。
  • 滚动升级中断后可以继续升级或受控回退，并在重新进入节点前核对现场版本。
  • 设置页保持紧凑双栏布局，升级状态、进度和历史记录继续由持久化任务恢复。

安全边界#

  • 升级维护期间继续暂停自动故障切换。
  • 上传和签名校验不会进入维护状态，也不会修改数据库。
  • 只有执行升级后才建立维护门禁；全部节点和 Raft 多数派验证通过后才释放。
  • 目标与回退 RPM 均包含在签名升级包内。

升级路径#

当前运行 2.2-40 时，直接上传：

clusterguard-ha-2.2-40_to_2.2-42.x86_64.cgupgrade

已经运行 2.2-41 时，上传：

clusterguard-ha-2.2-41_to_2.2-42.x86_64.cgupgrade

先生成只读计划，再于维护窗口执行滚动升级。升级期间持续观察数据库主从、业务入口、VIP 和 Raft 多数派状态。
