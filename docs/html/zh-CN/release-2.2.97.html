ClusterGuard HA 2.2-97#

日期：2026-09-09。架构：x86_64。用户手动升级，不直接部署。

修复内容#

本版补齐操作锁的执行函数和异步流程校验，不是只改按钮颜色。

  • 保留 96 的灾难恢复锁定：未解锁不能进入预检或提交恢复；仍需集群名确认、隔离风险勾选和后端安全检查。
  • MySQL、PostgreSQL 的主库切换和复制修复在函数层拒绝重复事件，校验权限、当前集群、目标及观测就绪状态。
  • 旧主恢复等待 discover/预检，以及 MySQL 全量重建等待同步预检时，重锁、换集群、刷新、换目标、权限或会话失效后，迟到响应不能继续发起执行。
  • 保留同一次明确授权操作的正常 stale_plan 预提交重试；外部重锁后禁止重试。内部观测刷新不重新解锁其他按钮。
  • 不改变已受理后台任务的执行或状态追踪，不改 fencing、writer lease、多数派、维护门禁、数据库算法。
  • 页面静态结构和 CSS 与 96 逐字不变，保留经典样式、日志工具栏、跟随集群筛选及分页加载。

升级文件#

仅选择与三台当前控制节点版本匹配的升级包，在控制台升级弹窗上传。完成后重新加载页面，已打开的旧页面不会自动替换正在运行的 JavaScript。

验证结果与边界#

  • 修改前同组 19 项测试中 17 项失败；修改后 19 项全部通过。原 16 项操作锁继承测试也全部通过，测试 API 完全隔离，不调用真实数据库。
  • 既有恢复弹窗、独立日志滚动、移动端边界、日志集群联动、分页 83 条保留、1,000 条日志不阻塞上下文测试通过。
  • Go 全仓测试、vet、API race、差异和格式检查通过；未修改的 Go 包可能使用缓存。
  • 两个签名包均完成公钥校验、篡改拒绝、回退 RPM、目标 RPM、载荷摘要及只读 inspect 验证。
  • 包内 HTML 与最终测试源码一致：fc92bb44f7ee5e946a0878c7724b44ed412a9663ba8686244c67654a96736e3c。与 96 对比，仅五个带版本的程序及 BUILD-INFO 摘要变化，其他 66 个文件不变。
  • 现场已安装 RPM 版本未查询，未部署 97，未进行现场上传、滚动升级或数据库灾难恢复演练。不将本地验收等同于整个 P0 已完成。
