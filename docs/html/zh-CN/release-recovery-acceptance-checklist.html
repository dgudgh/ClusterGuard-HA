恢复与升级发布验收清单#

完成判定#

编译、单元测试、直接安装 RPM、控制节点版本一致、页面显示成功，均不能单独作为现场验收完成的证据。没有执行的测试必须标为未执行。失败候选包不得覆盖原版本重打，必须明确撤回并使用新的补丁 ID。

修改前强制对比#

先遵守项目根目录 AGENTS.md。第一次修改业务代码前必须完成旧版对照并留下任务 Markdown；不能先改完再把对比补写成已事前完成。

  • 确认用户认可的旧版本、回归提交、当前工作树和当前发布包，不把当前 HEAD 当成全部版本。
  • 读取旧代码完整调用链，对比默认值、顶部选择联动、API 参数、异步状态与日志范围。
  • 记录应保留的旧行为、当前回归证据、拟改范围及验证方法；缺少可信基线先调查，不凭猜测修改。
  • 同一用户路径在修改前复现、修改后回归；不只检查截图、编译或当前实现的字符串。

已发生的联动回归和补查证据见 日志集群联动回归记录。

每次发布#

  • 核对真实源码目录、未提交改动、三台安装版本、当前数据库主从和维护状态。
  • 修改前旧代码对比记录齐全；顶部集群切换、日志范围、分页和迟到响应均按旧正确行为回归。
  • 完成全仓测试、关联竞态测试、vet 和差异检查。真实数据库测试必须显式提供运行环境；跳过不能记作通过。
  • 用现场信任公钥约束签名构建，保留完整来源 RPM、目标 RPM、签名升级包、SHA-256 和时间。
  • Chrome 点击升级：初始无旧包信息；文件选择器选择包；上传校验；弹窗显示校验完成；按钮由禁用变为可用；二次确认后执行。
  • 等待完整节点事件、最终状态和维护释放。不能把 3/3 控制程序版本一致当成数据库连续可用。
  • 两种数据库运行时，通过实际 VIP 连续执行只读 SQL，验证连接成功、原生主库身份和可写角色。升级前后对比容器 ID、启动时间、主从、links、VIP 唯一归属。
  • 最终版本分别完成至少 50 个不同后台 discovery observation：healthy、一主两从、两条安全 links、lag=0。读取旧 observation 50 次不算 50 个周期。
  • 使用原生 SQL 核对业务测试标记、节点 UUID、MySQL GTID 与 IO/SQL、PG receiver/application_name/物理槽。
  • 核对 Recovery Commit 与当前启停状态；历史 unplanned 保留，但不能把已恢复的当前状态显示为异常。
  • 上传前后比较既有审计文件 SHA-256。默认三个版本仅适用于安装材料，不能截断升级或操作日志；运行中和待复核任务的回退材料额外保护。
  • 实测桌面与窄屏标签切换、弹窗滚动、日志展开收起；操作标签在一行等宽，说明另行显示。
  • 发布说明区分代码、隔离原生测试、现场测试、升级包和未覆盖场景。

恢复场景必须分开测#

场景 必须证明
三节点全部停止 程序自行建立隔离证据、选出唯一安全主库、恢复从库、核对停机前测试数据
部分节点仍运行 程序完整隔离运行中的节点，SSH 超时不能把停库命令当成 5 秒查询；不能提前手动停掉节点来绕开此项
PG 分支冲突 system identifier、timeline 祖先、fork LSN、WAL 字节与独立 COMMIT/PREPARE；缺 WAL 或独立提交必须阻断
MySQL 分支冲突 GTID 集合包含、relay 排空、持久只读、native ID；独立事务、未决 XA、重启可写覆盖必须阻断
升级期间续租 已验签的 Agent 请求继续校验 Leader/quorum 和当前 lease；普通业务变更仍由维护门禁阻断
PG 主库与控制器同机 恢复 HBA 放行已配置的本机控制器精确 IP；保护仍生效时真实管理连接成功、非管理连接拒绝，不能只测试其他两台 peer
PG 旧失败任务续跑 字节与摘要匹配的旧保护文件才能迁移；保留原 HBA 和任务身份，篡改保护文件必须阻断
失败及接管 失败保持保护；重新预检重新取证；过期租约、签名错误、无多数派不能继续放行

禁止为了通过验收删除 fencing、放宽健康判断、延长短期签名许可、跳过事务分支检查，或手工设置健康状态。

工具与证据#

  • 浏览器交互回归：tools/console-recovery-acceptance.cjs。
  • 现场恢复准备、原生验证和 50 周期：tools/diagnostics/recovery-field-acceptance.py，仅用于明确授权的三台实验节点。
  • 运行中升级连续性：tools/diagnostics/release-continuity-field-check.py，baseline/monitor/verify，输出不含凭据。
  • 安装材料与审计保留：tools/diagnostics/release-retention-field-check.py。
  • PG 复制凭据旋转及验证：tools/diagnostics/pg-replication-secret-rotation.py。私有回执不能打印或放进支持包。
  • PG 同机控制器隔离验收：tools/diagnostics/pg-colocated-guard-field-check.py，只读且限时，不修改 HBA 或开放业务入口。

Docker Swarm 入口脚本是已发布 Config 时，仅替换宿主机 RPM 不会更新容器入口。必须单独记录原 Config、审核内容与新引用，并用容器重启验证旧 Bootstrap Env 不再覆盖运行态。

PXC/Galera 的 seqno/bootstrap 规则不能套用于普通 MySQL GTID 或 PostgreSQL WAL。未运行的引擎与部署形态不得列为已验收。
