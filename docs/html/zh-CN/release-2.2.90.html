ClusterGuard HA 2.2-90：恢复经典控制台，保留工具栏优化#

日期：2026-09-08。交付方式：签名升级包，由用户在控制台手动上传更新。本轮不部署现场。

本次范围#

  • 撤销 2.2-89 的米白纸感、鼠尾草绿配色、宋体标题和主题动画，恢复之前的白底、浅灰背景与蓝色操作按钮。
  • 保留数据库集群工具栏优化：标题旁显示数量，搜索与健康筛选对齐，窄屏分行；不再显示冗余的点击说明。
  • 只恢复主题样式，不回退功能代码。保留拓扑切换期间的集群名称、读取状态、失败重试、旧观测提示和请求代次保护。
  • 保留真实可切换的标签页、默认折叠升级日志、圆形阶段图标、固定升级摘要和独立滚动日志；手机日志换行不与相邻行重叠。
  • 不改变数据库恢复、fencing、writer lease、Raft 授权或安装包与审计日志的保留策略。

升级路径#

目标版本为 2.2-90，架构为 x86_64，分别提供：

当前安装版本 上传文件
2.2-88 clusterguard-ha-2.2-88_to_2.2-90.x86_64.cgupgrade
2.2-89 clusterguard-ha-2.2-89_to_2.2-90.x86_64.cgupgrade

查看控制台当前版本后只选择匹配的一份，不需要先安装 89。其他源版本不能用这两份包替代适配包。

在“设置 → 版本更新 → 升级”弹框中上传 .cgupgrade，等待签名与兼容性校验和计划准备完成，再确认滚动升级。升级期间仍受维护门禁和多数派授权约束，不绕过检查。

验证记录#

本轮通过 go test ./internal/api（1.008 秒），以及 go test ./internal/platformupdate ./scripts（升级管理器 2.637 秒，脚本回归 243.062 秒）。脚本回归采用临时目录和模拟 ssh/scp，覆盖签名与载荷校验、滚动顺序、门禁和回退场景，不是现场安装。

浏览器使用本次真实交付 HTML 和隔离 API 数据：

  • 工具栏在 1920、1440、1024、768、390、320 六种宽度下检查搜索、空结果、健康过滤、计数、键盘焦点、对齐、重叠与集群跳转。
  • 六个页面在四种宽度下共 24 组响应式截图；覆盖连续 12 次集群切换、延迟、503、15 秒超时、409 观测冲突、拓扑与启停乱序返回、辅助接口失败隔离。
  • 升级弹框空态、默认折叠日志、固定摘要、独立日志滚动、手机日志行边界和减少动态效果检查。
  • 恢复界面的确认、预检阻断、单次提交、重开进度、日志滚动、窄屏边界与阻断结果回归。

签名升级包的最终校验结果记录于交付目录 package-verification.json，包括签名、篡改拒绝、源与目标 RPM、引导升级器摘要，以及目标二进制内嵌页面与验收页面的一致性。各文件 SHA-256 见同目录校验文件。

验收边界#

本地预览 http://127.0.0.1:18789/ 仅使用 sample 集群与保留网段，不代表现场状态，也未改变现场 3000 端口。预览服务器拒绝所有写请求。

本轮未执行现场上传验签、真实滚动升级、数据库切换或灾难恢复，不以本地 UI 模拟结果声称这些操作已经通过。没有 SSH 登录现场、直接安装 RPM、重启数据库或解除维护门禁。现场当前版本未在本轮得到认证确认，按页面实际版本选包。
