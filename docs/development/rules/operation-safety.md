# 高风险操作授权规则

修改高风险入口、预检、授权、提交、重试、重复提交保护或会话失效处理前必须读取。刷新、换集群或请求晚到处理影响已有操作授权时也必须先读；前端、API 与执行器均适用。

## 必须保持与回归

- 新增高风险操作入口必须接入已有防误触锁，覆盖入口、预检和最终提交函数；禁止仅隐藏锁或只依赖按钮 disabled。重锁、换集群、刷新和会话失效必须使旧确认失效，迟到预检不得重新解锁。恢复进度查询不得因此取消后台任务。
- 普通切换、旧主恢复、复制修复也必须在执行函数中拒绝重复提交并绑定用户、集群和目标；每次异步预检后的执行及重试前重新验证授权。仅同一流程内部的观测刷新可以保留该流程授权，不能重新解锁其他操作；必须测试外部重锁/刷新/换集群/会话失效发生在 await 期间的情况。
