# 阅读优先级与适用规则

任何修改前先读[门禁执行与更新流程](../../zh-CN/validation-gate-workflow.md)；涉及契约范围时先完整读[强制契约 v2](../../zh-CN/upgrade-validation-chain.md)。随后用本索引找到其他适用规则，不要求读完全部正文。

## 阅读顺序

| 优先顺序 | 读取内容 | 时机与边界 |
| --- | --- | --- |
| 修改前先读 | 根规则、门禁流程、适用强制契约 | 先于模块导航；不得被功能说明或旧报告替代 |
| 当前任务必读 | 修改证据规则、当前模块/单功能、下表触发的授权/交互/许可等规则 | 第一次业务编辑前完成旧版对照；只展开涉及的功能 |
| 动作前必读 | 构建、签名、渠道、恢复和现场验收清单 | 在相应动作开始前读取；不能等包已构建或动作已执行后补读 |
| 追溯时按需 | 设计、发布记录、故障记录和历史验收报告 | 用于确定旧身份/行为与原始证据，不替代当前规则或本次验收 |

历史材料若用于旧版对照，仍须在第一次业务编辑前读取并记录；“按需”不允许把必需证据留到修改之后。遇到“需要时再读”时，按具体功能页写明的触发条件判断，不把条件必读降成可选。

## 触发规则

| 原 AGENTS 主题 | 当前正文 | 必读时机 |
| --- | --- | --- |
| 修改前旧代码对照、证据和验收真实性 | [修改与证据](change-policy.md) | 任何业务代码修改前 |
| 页面风格、实际点击、桌面/窄屏 | [前端通用交互](frontend-common.md) | 任何前端显示、状态、布局或交互修改前 |
| 风险确认、授权撤回、预检迟到、重复提交 | [操作授权](operation-safety.md) | 新增/修改变更入口、执行/重试链或会话撤权处理前 |
| 集群上下文、日志分页、节点弹窗、恢复等专项回归 | [前端页面入口](../frontend/README.md)、[后端功能入口](../backend/README.md) | 修改实际涉及功能前读取其中必守/回归条目 |
| 公开 Release 资产与删除义务 | [公开渠道](public-release.md) | 构建、公开上传/删除/核验 Release 或处理交付物前 |
| 许可、依赖、许可入包 | [许可与依赖](licensing.md) | 依赖、许可陈述、打包或涉及许可的对外交付修改/执行前 |
| 完整打包前阻断清单 | [交付清单](release-checklist.md) | 准备构建新交付物或正式发布前 |

普通文档改动仍须执行根规则规定的许可校验；只有修改许可陈述等对应事项时，才需要展开完整许可规则。

旧记录说“见 AGENTS”时，从[根规则](../../../AGENTS.md)确定任务范围，再到此表对应正文；不要把旧历史结论当作当前实现。
