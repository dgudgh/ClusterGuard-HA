# ClusterGuard HA 2.2-97

日期：2026-09-09。架构：x86_64。用户手动升级，不直接部署。

## 修复内容

本版补齐操作锁的执行函数和异步流程校验，不是只改按钮颜色。

- 保留 96 的灾难恢复锁定：未解锁不能进入预检或提交恢复；仍需集群名确认、隔离风险勾选和后端安全检查。
- MySQL、PostgreSQL 的主库切换和复制修复在函数层拒绝重复事件，校验权限、当前集群、目标及观测就绪状态。
- 旧主恢复等待 discover/预检，以及 MySQL 全量重建等待同步预检时，重锁、换集群、刷新、换目标、权限或会话失效后，迟到响应不能继续发起执行。
- 保留同一次明确授权操作的正常 stale_plan 预提交重试；外部重锁后禁止重试。内部观测刷新不重新解锁其他按钮。
- 不改变已受理后台任务的执行或状态追踪，不改 fencing、writer lease、多数派、维护门禁、数据库算法。
- 页面静态结构和 CSS 与 96 逐字不变，保留经典样式、日志工具栏、跟随集群筛选及分页加载。
