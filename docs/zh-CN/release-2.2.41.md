# ClusterGuard HA 2.2.41 发布说明

> **语言：** [English](../en-US/release-2.2.41.md) | 简体中文

发布日期：2026-08-28  
版本：`2.2-41`

## 版本概述

`v2.2.41` 完善图形化滚动升级的进度呈现和控制节点切换期间的状态接续。本版本只更新 ClusterGuard 控制面、Agent 和升级工具，不修改数据库软件、数据目录、复制关系或业务入口。

## 主要变化

- 执行、续跑或回退任务确认后，自动打开升级进度弹窗。
- 显示安全准备、节点滚动、集群验证和完成四个真实阶段。
- 显示当前节点、已验证节点数、维护门禁、版本变化和最近升级事件。
- 弹窗可转入后台，顶部维护提示提供“查看进度”入口。
- 页面刷新后根据持久化任务记录恢复进度。
- 升级事件和状态同步到所有控制节点，Raft Leader 重启或切换后由新 Leader 接续展示。
- 自动回退完成后明确记录为“已回退”，不再笼统显示升级失败。

## 安全边界

- 升级维护期间继续暂停自动故障切换。
- 进度百分比表示已完成的安全步骤，不是预计耗时。
- 升级顺序仍为跟随控制节点、纯数据节点、Raft Leader。
- 所有节点完成版本、就绪状态、Raft 多数派和维护门禁验证后，任务才返回成功。

## 升级路径

从 `2.2-40` 升级时，请在控制台上传同一 Release 提供的：

```text
clusterguard-ha-2.2-40_to_2.2-41.x86_64.cgupgrade
```

先生成只读计划，再于维护窗口执行滚动升级。升级期间持续观察数据库主从、业务入口、VIP 和 Raft 多数派状态。
