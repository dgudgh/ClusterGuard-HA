This directory preserves historical design specifications and implementation plans. English originals live in `plans/` and `specs/`; Simplified Chinese counterparts live in `zh-CN/plans/` and `zh-CN/specs/` with the same filenames.

本目录保存历史设计规格和实施计划。英文原文位于 `plans/` 与 `specs/`，简体中文对应版本位于 `zh-CN/plans/` 与 `zh-CN/specs/`，文件名保持一致。

## Document Status / 文档效力

- These records explain why a capability was designed or implemented.
- They are not installation instructions, current support claims, or production runbooks.
- Current changes and actions follow the repository rules and applicable mandatory contracts. A release's `RELEASE-INFO`, checksums, release notes, and matching operations manual identify that delivered artifact and explain its historical behavior; they cannot override current mandatory rules.
- Commands and acceptance results in dated plans must not be reused without revalidation.

- 这些记录用于解释能力的设计与实施背景。
- 它们不是安装手册、当前支持声明或生产操作手册。
- 当前修改和动作遵守根规则及适用强制契约。对应 Release 的 `RELEASE-INFO`、摘要、发布说明和同版本操作手册用于确认已交付制品身份及历史行为，不能覆盖当前强制规则。
- 带日期计划中的命令和验收结果，未经重新验证不得直接用于生产。
