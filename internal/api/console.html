关于 ClusterGuard HA

Multi-Database High Availability Control Plane

ClusterGuard HA

ClusterGuard HA 多数据库企业级高可用控制平台

独立的控制内核，以不可变平台资源 ID 和数据库原生身份管理可变主机名、IP 与端口。MySQL 已接入发现、拓扑、候选评估、切换、恢复、VIP、节点生命周期、审计和报告工作流。

PostgreSQL 已接入发现、主备拓扑、流复制健康、候选评估、受控切换、故障恢复、旧主回挂、节点同步、原生指标、审计和报告工作流。Oracle Data Guard Broker 与 SQL Server Always On 已接入只读发现、健康、拓扑、候选评估和受控切换入口；具体执行只在原生命令工具、凭据、门禁和验证证据真实可用时开放，未实现能力明确返回 unsupported。
